# ADS Jarvis Android Standalone

Independent Android prototype. This is NOT GreenSoil AIRA, OpenClaw, or a trading bot. No shared keys, services or data.

v0.3: Android Java prototype with animated orb, device speech recognition, TTS, Tamil/English toggle, local one-item memory and Settings intent. No Gemini integration yet.

Build: GitHub Actions `ADS Jarvis Standalone Android Debug` workflow (after files are uploaded). Debug build only; never publish keys.
